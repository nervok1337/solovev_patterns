# Автоматизация сети ресторанов «Ромашка»

Учебный проект по дисциплине «Шаблоны проектирования». Проект описывает
информационную систему для автоматизации работы сети ресторанов «Ромашка».

## Назначение проекта

Система должна охватывать следующие направления:

- складской учёт продукции;
- производственный учёт;
- сопровождение курьерской службы;
- финансовый учёт и взаиморасчёты;
- учёт персонала;
- оперативный контроль.

## Используемые технологии

- Python 3.x;
- SQLite;
- Swagger;
- HTML;
- JavaScript.

## Структура репозитория

```text
.
├── Docs/
│   ├── CodeCases.md         # требования к исходному коду
│   ├── Entities.md          # описание предметных сущностей
│   └── Technicaltask.md     # техническое задание

│   │   └── entity.py       # базовый класс сущности

│   └── Models/             # доменные модели
├── Tst/
│   ├── Functional/         # функциональные и e2e-тесты
│   ├── Integration/        # интеграционные тесты
│   └── Unit/               # модульные тесты
└── readme.md                # описание проекта
```
