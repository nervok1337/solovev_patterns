# Примеры сериализации

Файлы получены преобразованием объектов через `convert_factory.create(source)`
и сохранением результата стандартной функцией `json.dumps` с параметрами
`ensure_ascii=False`, `indent=4`, `allow_nan=False`. Кодировка файлов — UTF-8.

- `nomenclature_group.json` — группа «Продукты» (`nomenclature_group_model`):
  пример простых строковых полей и унаследованных свойств.
- `dated_group.json` — тестовая модель `dated_group_model` из
  `Tst/Unit/test_convert_factory.py`: простые поля, дата с часовым поясом
  и ссылка на группу «Продукты». Дата преобразована в строку ISO 8601.
- `recipe.json` — рецепт «Молочная карамель» из начальных данных
  `storage_manager`: вложенный рецепт, списки ингредиентов, номенклатура,
  группы и единицы измерения. Строки и числа сохраняют свои типы.

Группа и рецепт взяты из одного экземпляра хранилища, заполненного вызовом
`storage_manager.convert(settings_model())` с настройками по умолчанию.

Циклическая ссылка `base_range` базовой единицы измерения представлена словарём
с её `unique_code`. Свойства `id` и `unique_code` возвращают один идентификатор
модели; оба сохранены как публичные свойства исходного объекта.

Идентификаторы созданы моделями при генерации примеров. При повторном создании
объектов они будут другими.
